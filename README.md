# 省域数字经济发展水平的综合评价、障碍诊断与趋势预测

校大学生数学建模竞赛方案。围绕“评价—诊断—预测—对策”主线，用 Python 完整复现我国 31 个省（区、市）数字经济发展水平的测度、障碍因子识别与未来五年趋势预测，全流程无需手工调参、结果可复现。

## 方法链

| 子问题 | 模型 | 作用 |
| --- | --- | --- |
| 数据预处理 | 指标正向化 + 极差标准化 | 统一量纲与方向，映射到 [0,1] |
| 问题一 | 熵权法 → TOPSIS → Ward 系统聚类 | 客观赋权、贴近度排序、划分三大梯队 |
| 问题二 | 障碍度模型 | 指标层 / 维度层制约因子诊断 |
| 问题三 | 灰色 GM(1,1) | 小样本趋势外推 + C/P/MAPE 精度检验 |
| 问题四 | 分梯队政策建议 | 差异化对策 |

指标体系覆盖数字基础设施、数字产业化、产业数字化、数字创新能力、数字普惠五个维度共 11 项指标（含 1 项负向指标）。

## 快速开始

```bash
pip install -r requirements.txt
cd code
python main.py            # 建模计算 + 生成图表与 Excel
python build_report.py    # （可选）生成 Word 论文，需先运行 main.py
```

固定随机种子 `20240520`，任意机器重复运行结果一致。

## 主要结果（随示例数据）

- 熵权前三：软件业务收入 11.641%、企业电子商务销售额 11.388%、信息技术专利授权 10.992%。
- TOPSIS 前五：北京 0.958、广东 0.941、上海 0.936、江苏 0.918、浙江 0.872；Ward 聚类分为 5 / 14 / 12 省三个梯队。
- 首要障碍因子：软件业务收入、信息技术专利、电子商务销售额、5G 基站数。
- GM(1,1)：后验差比 C=0.0103、小误差概率 P=1.000、MAPE=0.217%，精度一级（优）；全国指数由 2024 年 0.5084 升至 2028 年 0.7908，年均增长约 11.68%。

## 数据说明

为保证开箱即可运行，`main.py` 的 `build_dataset()` 内置了一套**按各省真实发展梯度构造、固定随机种子的等口径示例数据**。正式使用时，将其返回的两张表替换为《中国统计年鉴》、工信部统计公报、北京大学数字普惠金融指数等真实数据（保持列名与指标方向一致），后续熵权、TOPSIS、障碍度、GM(1,1) 及全部图表会自动重算，模型代码无需改动。
